# Automated Braking System — Bachelor Thesis

**Bachelor's Thesis** developed at the **Technical University of Munich (TU Munich)**  
at the *Munich Institute of Robotics and Machine Intelligence (MIRMI)* lab.

> ⚠️ **Note:** This project requires proprietary **National Instruments (NI) hardware**  
> and **LabVIEW** software to run. It cannot be executed on a standard laptop or PC.  
> The files are provided here for documentation and portfolio purposes only.

---

## Project Overview

Designed and engineered an **automated braking device** for a human-robot interaction  
test stand, used to analyze effective robot masses during pendulum impact tests.  
The system detects robot impact and automatically halts pendulum rebound to prevent  
secondary collisions — ensuring safety in the test environment.

The project was developed following **VDI-2222** engineering design guidelines and  
successfully validated through manual and reliability testing.

---

## What Was Built

- Real-time control software in **LabVIEW** using **NI hardware** and **FPGA-based servo control**
- Motion detection system to trigger braking after robot impact
- 3D mechanical models for the braking assembly
- Automated testing and validation procedures
- Full technical documentation per VDI-2222 guidelines

## Why LabVIEW?

LabVIEW is a **graphical programming language** used in scientific and engineering  
environments for real-time data acquisition and hardware control. Unlike text-based  
languages, programs are built as visual block diagrams — making it the industry  
standard for NI hardware integration and test automation.

The files in this repository (`.vi`) are LabVIEW Virtual Instruments — they can only  
be opened and run with a licensed LabVIEW installation connected to the required  
NI hardware.
